## AI 分类流程

```
规则未覆盖的书签 (约12%)
       │
       ▼
┌─────────────────────────────────────┐
│  构建 Prompt                        │
│  System: 分类助手 + JSON格式要求     │
│  User: 标题/URL/域名/描述/关键词/正文 │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│  调用 DeepSeek API (Bearer Token)    │
│  /v1/chat/completions               │
│  temperature=0.1 (稳定输出)         │
│  response_format=json_object        │
│  重试: 指数退避 (2s→4s→8s)         │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│  解析 JSON 响应                     │
│  验证 L1/L2 在分类体系中             │
│  模糊匹配 + 默认值兜底               │
│  置信度裁剪 [0, 1]                  │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│  缓存结果 + 回写书签                 │
│  颜色标记: 🟠橙色 (AI推测)          │
└─────────────────────────────────────┘
```
