🚀 快速开始
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【方式一】源码运行 (开发/调试)

    1. 解压 ZIP
    2. uv sync                           # 安装依赖
    3. uv run python main.py             # 启动

  【方式二】打包为 exe

    1. 解压 ZIP
    2. uv run python build.py
    3. 输出: dist/BookmarkManager.exe

  【方式三】便携版

    1. 解压 ZIP
    2. 运行 build.py 生成便携版目录
    3. 复制整个目录到任意位置使用

  🔁 传统方式 (无 uv):
    pip install -r requirements.txt && python main.py
