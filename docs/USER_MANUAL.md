## 功能简介

收藏夹管理工具是一款专为重度浏览器用户设计的**书签智能分类工具**。它能：

| 功能 | 说明 |
|---|---|
| 📤 自动导出 | 一键导出 Chrome/Edge 书签，文件名带毫秒时间戳 |
| 🔍 智能分类 | 三级引擎：规则匹配（88%覆盖）→ 网页抓取 → AI 理解 |
| 🌐 网页抓取 | Scrapling + requests + Firecrawl 三重兜底 |
| 🤖 AI 分类 | DeepSeek API 智能理解网页内容并归类 |
| 📊 审核确认 | Excel 表格 + 内置对话框，颜色编码一目了然 |
| 📁 两级分类 | 12个一级分类 × N个二级分类，生成标准 Netscape HTML |
| 📥 一键导入 | 向导式引导导入 Chrome/Edge，含备份保护 |
| 🔒 安全可靠 | API Key 本地加密，代理支持，原书签自动备份 |

## 安装与启动

### 方式一：便携版（推荐）

1. 下载 `BookmarkManager_v1.0.zip`
2. 解压到任意目录（如 `D:\Tools\BookmarkManager\`）
3. 双击 `BookmarkManager.exe` 启动

### 方式二：源码运行

```bash
# 1. 克隆或解压源码
cd BookmarkManager

# 2. 安装依赖 (使用 uv，推荐)
uv sync

# 3. 启动
uv run python main.py
```

> 传统方式（无 uv）：`pip install -r requirements.txt && python main.py`

### 首次启动

首次启动会：
1. 自动创建 `data/` 目录（缓存/备份/日志）
2. 加载默认配置（12个分类体系）
3. 检测系统代理设置
4. 显示主界面

## 快速上手（5分钟）

### Step 1: 选择浏览器

```
主界面顶部 → 浏览器下拉框 → 选择 "Chrome" 或 "Edge"
```

### Step 2: 点击「🚀 开始导出并解析」

程序会：
- 检测浏览器是否运行（运行中会提示关闭）

规则引擎自动分类，约 30ms/1000条。

### Step 4: 审核确认

审核对话框弹出后：
- ✅ 确认全部 → 点击「全部确认」
- 🔄 修改分类 → 下拉选择新分类
- 🗑️ 删除 → 勾选删除列

### Step 5: 生成 & 导入

- 点击「生成 HTML」
- 导入向导自动弹出
- 选择浏览器 → 按提示操作

## 详细使用指南

### ① 导出与解析

#### 自动导出

点击「🚀 开始导出并解析」后：

1. **进程检查**：检测 Chrome/Edge 是否在运行
   - 如果运行中 → 弹出提示要求关闭
   - 原因：浏览器锁定文件，无法读取

2. **Profile 选择**：
   - 默认 `Default`
   - 多账号用户可选择 `Profile 1`、`Profile 2` 等
   - 也可手动指定路径

3. **导出文件**：
   - 格式：Netscape Bookmark HTML
   - 命名：`bookmark-YYYYMMDDHHmmssSSS.html`
   - 位置：`data/exports/`

4. **解析结果**：
   - 表格预览（最多显示200条）
   - 统计信息：总数/域名数/文件夹数
   - 分类分布树

#### 手动导入 HTML

如果你已有导出的 HTML 文件：
- 菜单 → 文件 → 导入 HTML
- 选择文件 → 自动解析

### ③ 网页抓取

#### 何时触发

规则未覆盖的书签 → 自动进入抓取队列

#### 抓取引擎

```
1️⃣ Scrapling (首选)  → 强反爬绕过
2️⃣ requests (兜底)   → 轻量快速
3️⃣ Firecrawl (终极)  → API 付费，处理 SPA
```

#### 抓取内容

- 网页标题
- Meta 描述
- 关键词
- 正文摘要（前500字）

#### 跳过规则

以下类型**不抓取**（无意义）：
- YouTube/Bilibili 视频页
- Twitter/X 推文
- PDF/图片/视频文件
- `chrome://` 内部页面
- 内网/本地地址

#### 代理支持

- HTTP/HTTPS/SOCKS5
- 系统自动检测
- 自定义地址
- 绕过规则（内网直连）
- 可单独配置是否走代理

### ④ AI 分类（DeepSeek）

#### 配置

设置 → AI 配置 → 填入 DeepSeek API Key

获取方式：
1. 访问 https://platform.deepseek.com/
2. 注册登录 → API Keys → 创建
3. 复制 Key → 粘贴到设置

#### 费用估算

| 项目 | 数值 |
|---|---|
| 每条书签消耗 | ~1100 tokens |
| 输入价格 | ¥0.014/千 tokens |
| 输出价格 | ¥0.028/千 tokens |
| 单条成本 | ~¥0.04 |
| 100条成本 | ~¥4.00 |
| 默认预算上限 | ¥5.00 |

#### 分类流程

```
URL + 网页内容 → Prompt 构建 → DeepSeek API → JSON 解析 → 分类结果
```

#### 重试与缓存

- 失败自动重试（指数退避：2s→4s→8s）
- 结果缓存（同一 URL 不重复调用）
- 预算超限自动停止

## 常见问题

### Q: 导出时提示"浏览器正在运行"

**A:** 关闭所有 Chrome/Edge 窗口（包括后台进程），再重试。
- Windows: 任务管理器结束 `chrome.exe` / `msedge.exe`
- macOS: 右键 Dock 图标 → 退出
- Linux: `pkill chrome` / `pkill msedge`

### Q: AI 分类费用太高怎么办？

**A:** 几种省钱方法：
1. 先让规则分类跑完（免费，覆盖 88%）
2. 只对"待AI"的书签启用 AI
3. 降低温度到 0.1（输出更短）
4. 提高缓存命中率（同一 URL 不重复）

### Q: 抓取失败很多

**A:** 检查：
1. 代理是否配置正确（点「测试代理」）
2. 是否需要登录才能访问
3. 是否被反爬拦截（换 UA / 加延迟）
4. 用 Firecrawl 作为终极兜底

### Q: 生成的 HTML 导入后乱码

**A:** 确保：
1. 导出时选择 UTF-8 编码
2. 浏览器版本较新（Chrome 90+）
3. 不要手动编辑 HTML 破坏结构

### Q: 能处理 Firefox 吗？

**A:** 当前版本仅支持 Chrome/Edge。Firefox 的 JSON 格式不同，将在 v1.1 支持。

### Q: 书签超过 5000 条会卡吗？

**A:** 不会。设计上支持万级书签：
- 解析：流式处理
- 分类：O(1) 哈希查找
- 表格：虚拟滚动（只渲染可见行）
- 抓取：后台线程 + 进度反馈
