📥 如何导入浏览器？
  1. 打开 Chrome/Edge 浏览器
  2. 进入书签管理器（Chrome: chrome://bookmarks / Edge: edge://favorites）
  3. 点击 ⋮ → 「导入书签」→ 选择刚下载的 HTML 文件
  4. 导入后书签出现在「导入的书签」文件夹中

❓ 使用说明

  1. ① 上传书签文件 — 在浏览器中「导出书签」得到 bookmarks.html（或使用 Chrome 的 Bookmarks JSON 文件），拖入页面。
  2. ② 自动处理 — 系统自动完成：链接体检（区分本地/失效）→ 网页抓取 → AI 自动分类。
  3. ③ 审核结果 — 切换筛选「待分类」逐条确认分类，本地/内网书签可一并核对，失效链接一键删除。
  4. ④ 导出 — 下载标准 Netscape HTML，再到浏览器「导入书签」即可。

💡 访问国外网站资料需要代理时，请先在 ⚙️ 设置 中启用并填写代理地址。
